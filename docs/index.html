The four methods are PCA, t-SNE, UMAP, and PHATE. Saved coordinates let the examples run immediately after base setup. Recomputing UMAP or PHATE requires the additional packages described on the notebook page.

What to investigate

Compare an embedding without color, an input-feature overlay, a missingness overlay, and a withheld outcome overlay. Select a region and return to the original variables. Then ask which interpretation survives a reasonable alternative view.

The methods guide summarizes strengths and limitations. Run details documents the data, preparation, implementations, and settings.

Optional tornado practice

Use a fixed 700-record sample from the Day 1 dataset, which covers 4,706 whole tornado tracks from 2015-2018. Construct profiles from track size and starting location, then overlay EF rating. The exercise is outside the required 50-minute class.
